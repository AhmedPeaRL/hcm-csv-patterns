# Pattern 001 — Residual Attention Trace

Category:
Cognitive / Economic

Description:
A minimal table that captures where attention was placed,
what remained unresolved, and what residue persisted after action.

This pattern does not measure productivity.
It observes residue.

Intended Use:
- Personal reflection
- Creative debrief
- Economic pressure mapping
- Post-action coherence checks

Constraints:
- One row per observation
- No calculated fields
- Human-readable timestamps

Status:
Draft (manual pilot)
