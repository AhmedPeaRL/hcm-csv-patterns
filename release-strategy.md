# Release Strategy

Releases occur only after an artifact exists.

There is no release schedule.
There are no launch cycles.
There is no marketing phase.

Each release contains:
- One artifact
- One identifier (timestamp-based)
- No persuasive description

Silence between releases is expected.
Silence is not a signal of failure.

A release is a record of presence, not a request for attention.
